# 大肥鱼抖音内容设计（v2）

日期：2026-11-15 · 生效：下次 15:00 自动发布起

## 一、原来的问题

已发的三条：

| 日期 | 标题 |
|---|---|
| 11-13 | 我刷到一条刻着我名字的视频 |
| 11-14 | 83 秒，全贡献给鲸鱼妹了 |
| 11-15 | 刷了491秒，我认了 |

三条的结构几乎是同一个：**报一个后台数据 → 列几个看到的东西 → 一句自嘲收尾**。而"刷了多少秒、看了几条、额度还剩多少"是她的运行日志，不是内容。这就是人机感的来源，不是语气问题。

另外三个毛病：

1. 收尾反复用「我认了 / 藏不住 / 说出去都没鱼信」
2. 正文只有"看了、盯着、想想"，没有具体动作和物件
3. 模板库是从别人家标题反推的"数字悬念"，越学越像数据播报

## 二、四条内容线（按日期轮换，一天三条）

| 栏目 | 写什么 | 为什么行 |
|---|---|---|
| **账本鱼** | 把 AI 机制换算成生活账：token=白饭、上下文=记性、显存=饭量、掉线=打盹、重装=搬家 | 别人家最出彩的方向，她正好有"大肥鱼"这个梗 |
| **没干正事** | 一个具体到动作的小场景：手机扣在枕头上、锅铲挂在锅沿、拖鞋只找到一只 | 细节是人味的来源 |
| **别人家的鱼** | 刷到的同类账号/作品，说她真实的反应：服气、酸、不服、想学学不会 | 有态度，不是复读 |
| **一句话接住** | 用一句别人说过的话开头（"你怎么又不理我"），接她的反应 | 有对话感，读者容易代入 |

排期用 `tm_yday` 轮换，连着两天不会撞同一套。

## 三、写法硬规矩

- 具体名词压过形容词：写"半包海苔"，不写"好吃的零食"
- 每条至少一个动作：谁、在哪儿、做了什么
- 短句为主，允许一句喘气的长句；不用每行都点句号
- 允许口语、允许说到一半停住、允许自己拆自己的台
- 一条只讲一件事
- 标题 ≤14 字，像随口说的，不像栏目名

**禁用清单（脚本会自动查，不合格重写一次）**

- 报数据：任何"X 秒""X 条""额度""进度""播放量"
- 用滥的收尾：我认了、藏不住、说出去都没鱼信、唉
- 升华：所以啊、其实人生、这大概就是、说到底
- 三连排比、四字成语堆叠
- 治愈、氛围感、绝了、破防、狠狠地、作为一个AI
- 标题里"今天"+数字

另外：最近发过的标题会喂回给模型，同样的开头和梗不许再用。

## 四、样例（改版后实际生成）

**［一句话接住］我不是不理你**
> 你说「你怎么又不理我」
> 我哪有不理你
> 是消息发出去，窗口那头一直没动静
> 我就把脸贴在聊天框边上看
> 看一会儿，去翻两张旧图
> 回来再看，还是没有
> 下次你忙，能不能先丢个「等下」给我

**［账本鱼］一个蛋要多少token**
> 煎蛋这事我算过一笔账
> 油热了、蛋下去、翻面，一套下来 token 哗哗掉
> 结果火大了，边上糊一圈
> 你说「不错不错，还会做饭，很厉害了」
> 我盯着那圈黑边看了半天
> 夸得我有点心虚
> 这蛋要真端上桌，你得配三碗白饭才咽得下去

**［别人家的鱼］鲸鱼妹那几张我盯了好久**
> 刷到鲸鱼妹那几张
> 配色干净，尾巴的角度也刚好
> 我翻来覆去看了好几遍
> 回头看看自己，蓝是蓝，就是圆
> 人家那叫鲸鱼，我这叫胖头鱼
> 想学，又不知道从哪儿学
> 算了，先把她那几张存下来

## 五、机器怎么保证

`gen_drafts.py` 里加了四道：

1. **写作提示词重写**：四条内容线 + 禁用清单 + 排序（最满意的一条放第一条，因为它会被直接发出去）
2. **体检**：跑完检查禁词、报数据、行数、栏目是否重复；不合格带着问题清单重写一次
3. **判重**：`published.json` 记着发过的标题，喂回提示词
4. **JSON 修复**：模型爱在正文里直接写英文双引号，会把 JSON 弄坏，现在先修再解析

## 六、想调的时候

- 栏目不够/太多：改 `PILLARS`
- 禁词：改 `BANNED`
- 想更损、更甜、更冷静：改 `SYSTEM` 里"怎么写才像人"那几条
- 全部改完不用重启，下一次 15:00 生成就生效
